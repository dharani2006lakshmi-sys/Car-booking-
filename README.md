## 🚀 Features Overview

- **Vehicle Catalog:** Features a wide array of electric vehicles including the BMW i4, BYD Seal, Hyundai Creta EV, and more.
- **Static Performance:** Blazing fast load times utilizing pure HTML, CSS, and Vanilla JavaScript.
- **Responsive Layout:** Beautiful grid system ensuring perfect viewing on mobile devices and large screens alike.
- **Interactive Booking:** Seamless user interface designed to maximize conversion rates for rentals.
